# Project Instructions

## Local progress tracking

`COURSE_PROGRESS.md` and `SESSION_HANDOFF.md` are local working files and are
intentionally excluded from Git.

Whenever project work changes the current status, update both files locally as
part of the same work session. Do this even when the project owner has not had
time to work on or update the project personally.

- Keep `COURSE_PROGRESS.md` as the detailed, canonical record of completed
  work, decisions, validation, blockers, and the exact next action.
- Keep `SESSION_HANDOFF.md` as a concise restart summary that agrees with
  `COURSE_PROGRESS.md` and the actual repository state.
- Before editing either file, inspect the repository and preserve any progress
  recorded by the project owner.
- Record only verified work. Do not infer that an unobserved task was completed.
- Never place passwords, tokens, private keys, or other secrets in either file.
- At the end of each work session, check that the current lesson or phase,
  blocker, last completed checkpoint, and next action are accurate.
