# Mini SOC Lab Objectives

## Primary Objective

Build an isolated security operations environment capable of collecting,
detecting, investigating, and documenting controlled security activity.

## Systems

- One Wazuh central server
- One Windows endpoint
- One Ubuntu Linux endpoint

## Security Capabilities

- Centralized event collection
- Windows Sysmon monitoring
- Linux authentication monitoring
- File-integrity monitoring
- Custom Wazuh detection rules
- Sigma detection rules
- MITRE ATT&CK mapping
- Controlled adversary simulation
- Incident investigation
- Python-assisted reporting

## Required Outcomes

- At least 8 validated detections
- At least 8 MITRE ATT&CK techniques represented
- At least 3 formal investigation reports
- One Python alert-processing utility
- One architecture diagram
- One reproducible deployment guide
